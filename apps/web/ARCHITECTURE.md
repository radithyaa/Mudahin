# Arsitektur Frontend — Vertical Slice (`apps/web`)

Dokumen ini menjelaskan **aturan penulisan kode** frontend Mudahin. Baca ini sebelum menambah halaman/fitur baru.

> Ringkas: setiap fitur = **satu folder route** yang berisi **semua** kode khusus fitur itu (komponen, hook, lib, store, tipe). Kode hanya "naik" ke level global saat dipakai oleh ≥ 2 fitur.

---

## 1. Struktur Direktori

```

├── routes/                  # File-based route tree (TanStack Router) — VERTICAL SLICES

│   ├── routeTree.gen.ts     # Autogenerated — JANGAN edit
│   ├── index/               # Beranda ("")
│   │   ├── route.tsx
```

---

## 2. Aturan Emas

1. **Colocation** — kode yang hanya dipakai satu fitur tinggal di dalam `routes/<fitur>/`.
2. **Promote saat dipakai bersama** — pindah ke global (`components/`, `lib/`) **hanya ketika** dipakai ≥ 2 fitur.
3. **Satu arah** — fitur boleh import dari global & `packages/*`; **global tidak boleh import dari fitur**.
4. **`app/` = komposisi, bukan fitur** — provider, shell, dan layout hidup di sini. Jangan taruh logika fitur di `app/`.
5. **DTO di package** — tipe/skema yang dipakai client & server ditaruh di package bersama (`@mudahin/api`, `@mudahin/db`).

### Decision table

| Kode dipakai oleh | Tempatkan di |
|---|---|
| 1 fitur | `routes/<fitur>/<components\|hooks\|lib\|stores>/` |
| ≥ 2 fitur (web saja) | `apps/web/src/{components,hooks,lib}/` |
| ≥ 2 app / primitif UI | `packages/ui/src/...` |
| Kontrak API client–server | `packages/api` (tRPC + Zod) |

## 3. Anatomi Folder Route

```
routes/focus-reader/
├── route.tsx            # Definisi Route TanStack (layout/guard). Wajib bila ada anak.
├── index.tsx            # Halaman utama.
├── components/          # Komponen khusus fitur.
├── hooks/               # Hook khusus fitur (mis. use-text-to-speech.ts).
├── lib/                 # Util/konstanta khusus fitur.
└── stores/              # (opsional) slice Zustand khusus fitur.
```

**Konvensi nama berkas:** `kebab-case` (`reading-ruler.tsx`, `use-text-to-speech.ts`).

**Route TanStack Router:**
- Folder `routes/<nama>/index.tsx` → URL `/<nama>`.
- Folder `routes/<nama>/route.tsx` → layout (memakai `<Outlet />`) jika punya anak.
- Prefiks `_` = pathless (mis. `_auth/` untuk guard tanpa menambah segmen URL).
- `$materialId/index.tsx` → parameter dinamis `/materi/:materialId`.
- **Jangan edit** `routeTree.gen.ts` — dibuat otomatis oleh plugin saat dev/build.

---

## 4. Kapan `app/` vs `routes/`

| Aspek | `app/` | `routes/` |
|---|---|---|
| Isi | Provider, shell, layout, navigasi | Halaman & kode khusus fitur |
| Contoh | `ThemeProvider`, `AccessibilityApplier`, `AppHeader` | `NeedPicker`, `ReadingRuler` |
| Dipakai oleh | Seluruh aplikasi | Satu route (+ anaknya) |

`__root.tsx` tetap di `routes/` (wajib TanStack Router) dan **merakit** elemen dari `app/`:

```tsx
<ThemeProvider ...>
  <AccessibilityApplier />
  <AppHeader />
  <Outlet />
</ThemeProvider>
```

## 5. State & Aksesibilitas

- **Store global** hidup di `lib/stores/`. Store `focus-profile` adalah sumber kebenaran preferensi aksesibilitas (persist ke `localStorage`).
- **Penerapan ke DOM** dilakukan sekali di root oleh `app/providers/accessibility-applier.tsx` (menulis CSS variable & class: `--a11y-font-scale`, `data-font="dyslexic"`, `.high-contrast`, `.reduce-motion`).
- Kontrol aksesibilitas **reusable** ada di `components/accessibility/` (`QuickSettingsControls`, `SliderField`, `ToggleRow`) — dipakai halaman Pengaturan **dan** bottom sheet Pengaturan Cepat/Reader.
- Komponen **tidak** menempel style aksesibilitas manual; cukup gunakan token/var seperti `leading-[var(--a11y-line-height)]`.

Lihat `../packages/ui/src/styles/globals.css` untuk token warna & tema (dark/light/high-contrast).

---

## 5.1 Mobile-First & Gesture Friendly

Aplikasi ini **utamanya mobile**. Aturan pengalaman mobile:

- **Bottom tab bar** (`app/layout/mobile-tab-bar.tsx`) — hanya ikon + label `sr-only`, tampil di `< md`, tersembunyi di route fullscreen (`/onboarding`, `/login`).
- **Top app bar** (`app/layout/app-header.tsx`) — bar ringkas di mobile (logo + pengaturan cepat + tema + akun); nav teks muncul di `md+`.
- **Safe area** — gunakan `pt-[env(safe-area-inset-top)]`, `pb-[env(safe-area-inset-bottom)]`, dan `viewport-fit=cover` (lihat `index.html`).
- **Bottom sheet** — pakai `Drawer` dari `@mudahin/ui/components/drawer` (`swipeDirection="down"` + `showSwipeHandle`) untuk kontrol kontekstual: Pengaturan Cepat, Filter Pustaka, Pengaturan Reader.
- **Target sentuh** — minimal 44×44px (`min-h-11`/`min-h-14`).
- **Scroll lock & overscroll** — `overscroll-behavior-y: none` di `body`; input ber-font ≥16px agar iOS tidak auto-zoom.
- **Respect reduced motion** — jangan hardcode animasi; hormati `.reduce-motion` & `prefers-reduced-motion`.

## 6. Data Fetching

- Semua akses server lewat **tRPC client** (`@/utils/trpc`), dipakai bersama TanStack Query.
- **Jangan** `fetch()` ke DeepSeek/HTTP lain dari komponen. Tambah **prosedur tRPC** di `packages/api` terlebih dahulu.
- Data statis demo (mis. seed materi) boleh berada di `lib/<domain>/` selama belum ada endpoint.

---

## 7. Checklist Menambah Fitur

1. Buat folder `routes/<fitur>/` (+ `components/`, `hooks/` bila perlu).
2. Tulis `index.tsx` (atau `route.tsx` bila menjadi layout).
3. Simpan komponen/hook khusus di dalam folder fitur.
4. Kalau dipakai fitur lain → pindahkan ke `components/`/`lib/` global.
5. Jalankan `bun run fix` lalu `bun run check-types` dari root.
6. Verifikasi **keyboard + ARIA**, target sentuh ≥ 44px, dan kontras ≥ 4.5:1.

## 8. Menjalankan

```bash
bun run dev:web        # jalankan frontend saja (localhost:3001)
bun run dev            # frontend + server (turbo)
bun run check-types    # cek tipe (root)
bun run fix            # format + lint otomatis (Ultracite/Biome)
```
